# Разлагане на множители — интерактивен урок за 7. клас

Сайт за ученици: визуална идея („разлагането е търсене на страните на правоъгълник“), четирите начина като карти с картинки, тренажор „Детектив“, който води ученика стъпка по стъпка по блок-схемата, и шпаргалка.

Работи без сървър и без зависимости: отворете `index.html` в браузър.

## Структура

```
index.html          съдържание на страницата: начало, 4 инструмента, тренажор, блок-схема (SVG), шпаргалка
css/style.css       оформление; цветове и шрифтове са токени в :root, има тъмна тема
js/app.js           логиката на тренажора: мини-нотация за формули, състояние, стъпки, блок-схема, localStorage
data/tasks.js       14 задачи / 80 стъпки (window.TASKS) — ГЕНЕРИРА СЕ, не се редактира ръчно
tools/build_tasks.py  описание на задачите + автоматична проверка; записва data/tasks.js
tools/pz.py         малка библиотека за многочлени: проверява, че всеки междинен израз = началния
```

## Как работи тренажорът

Всяка задача е `{t: израз, g: група, steps: [...], fin: отговор}`. Всяка стъпка е въпрос с бутони:

```
{node: 'Q1'|'A1'|'Q2'|'B2'|'B3'|'B4'|'Q5',   # кой възел на блок-схемата свети
 q: 'въпрос', opts: ['...'], ok: индекс на верния отговор,
 hint: 'подсказка при грешка', note: 'бележка при верен отговор',
 e: 'нов израз след стъпката (по избор)'}
```

Възли на блок-схемата: `Q1` общ множител? → `A1` изнеси го → `Q5` още нещо?; `Q2` колко члена → `B2` (2 члена: квадрати/кубове), `B3` (3 члена: точен квадрат), `B4` (4 члена: групиране) → `Q5`; `Q5` да → обратно към `Q2`, не → `END`.

**Мини-нотация за формули** (в `t`, `e` и между `$...$` в текстовете): `x^2` степен, `*` или `·` умножение, `#` = ▢, `@` = ◯. Пример: `$#^2-@^2=(#-@)(#+@)$`.

## Добавяне на задачи

1. Добавете задача в `tools/build_tasks.py` (по образеца на съществуващите; има помощни функции `Q1`, `A1`, `Q2`, `B2type`, `Q5`).
2. Пуснете `python3 tools/build_tasks.py`. Скриптът спира с грешка, ако някой междинен израз `e` не е равен на началния или ако индексът `ok` е извън опциите.
3. Презаредете `index.html`.

## Идеи за развитие

- Повече задачи и нива (лесно / средно / НВО), случайно генерирани варианти със същите стъпки.
- Режим „свободен отговор“: ученикът пише разлагането, а то се проверява чрез разкриване.
- Анимация на картинките (квадратът без ъгъл се пренарежда в правоъгълник).
- Прогрес и статистика за учителя; печатна версия на задачите.
- Други теми от 7. клас по същия модел (ФСУ, уравнения).
